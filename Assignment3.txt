if unnecessary we need to kill it
kill -9 PID

if it is a service then we need to restart it 
systemctl restart servicename
if CPU stays high even after that we need to scale-up by providing or adding more CPUs

then we need to check the disk input output sometimes load is average is high because of slow or input output wait 
iostat -x 1 3

use faster disk like SSD
Split load across multiple disks
